# C Vector Implementation
Simple dynamic array implementation in C as a learning project

## Features
  * dynamic growth and shrinking
  * push and pop
  * insert and remove by index
  * get and set at an index
  * Opaque `Vector` type
  * `memmove` for memory shifting

## Files
  * vector.c - implementation
  * vector.h - API
  * vector_test.c - basic test program
  * Makefile - build configuration
